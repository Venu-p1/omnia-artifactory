Parameter

Details

provision_password

Always required. Use 8-32 single-line characters; commas, hyphens, and single or double quotation marks are not accepted.

bmc_username

Always required. Use 1-64 single-line characters; hyphens, backslashes, and single or double quotation marks are not accepted.

bmc_password

Always required. Use 3-32 single-line characters; commas, hyphens, backslashes, and single or double quotation marks are not accepted.

slurm_db_password

Required when Slurm or custom Slurm support is selected. Use 8-32 single-line characters; hyphens, backslashes, and single or double quotation marks are not accepted.

openldap_db_username

Required when the catalog enables OpenLDAP. Use 4-64 single-line characters; semicolons, square brackets, and backticks are not accepted.

openldap_db_password

Required when the catalog enables OpenLDAP. Use 8-32 single-line characters; hyphens, backslashes, at signs, and single or double quotation marks are not accepted.

openldap_bind_username

Required when the catalog enables OpenLDAP. Read-only account that LDAP clients bind with; Orchestrator creates it as cn=<username>,ou=ServiceAccounts,<base>. Use 4-64 characters that start with a letter; only letters, digits, periods, underscores, and hyphens are accepted.

openldap_bind_password

Required when the catalog enables OpenLDAP. Must differ from openldap_db_password. Use 8-32 single-line characters; hyphens, backslashes, at signs, and single or double quotation marks are not accepted. Written to sssd.conf on LDAP client nodes.

csi_username

Required when PowerScale CSI is enabled. Use 4-64 single-line characters; semicolons, square brackets, and backticks are not accepted.

csi_password

Required when PowerScale CSI is enabled. Use 5-32 single-line characters.
